# Анализ рынка Яндекс Игр

Дата: 19.08.2026. Источник: официальный портал [Яндекс Игры для разработчиков](https://yandex.ru/project/games/for-developers) и живой каталог [yandex.ru/games](https://yandex.ru/games/).

## 1. Платформа в цифрах (официальные данные Яндекса)

| Показатель | Значение |
|---|---|
| Доход топовых веб-хитов | до **1,5 млн ₽/мес** на игру |
| Аудитория | **миллионы игроков в месяц** по всему миру |
| Трафик | платформа сама находит игроков бесплатно (без обязательных закупок рекламы) |
| География | Россия 60% / мир 40% |
| Пол | **женщины 58%** / мужчины 42% |
| Возраст | **55+ = 38%** (ядро), 45–54 = 11%, 35–44 = 15%, 25–34 = 16%, 18–24 = 11%, <18 = 9% |
| Монетизация | реклама (rewarded/interstitial) + инап-покупки (IAP), мидкорных игр с IAP на платформе много |

**Вывод по аудитории:** ядро платформы — женщины 55+ из России. Они не любят сложные экшены, зато обожают казуальные игры с прогрессией: три в ряд, merge, экономические/тайкуны, головоломки. Это и есть самые прибыльные ниши при разумных затратах на разработку.

## 4. Выбор: «Бизнес-Империя» — idle-кликер-тайкун

Почему именно это:

1. **Попадает в ядро аудитории** — женщины 55+, простые правила, понятная тема «от ларька до корпорации», без экшена.
2. **Мета-прогрессия даёт деньги** — офлайн-доход, апгрейды, престиж — игрок возвращается ежедневно; каждый возврат = rewarded-реклама и IAP.
3. **Стартуем с готовой базы** — в проекте уже есть работающий шаблон кликера с интеграцией SDK (сохранения, лидерборд, реклама). Переделка в тайкун — быстрая.
4. **Тема без арт-затрат** — деньги, цифры, простые эмодзи-иконки: можно запустить красиво без покупного арта.
5. **Платформа продвигает бесплатно** — при хороших метриках удержания Яндекс сам даёт трафик.

Ожидания: средняя игра в этой нише — от 20 до 150 тыс. ₽/мес, хит (как «Ежики!» или «Дизайнер Чехлов») — миллионы игроков и до 1,5 млн ₽/мес. Это не гарантия, а ориентир: результат решают удержание (D1 ≥ 35%) и частота rewarded-рекламы.
