# GDD: «Бизнес-Империя» (idle-кликер-тайкун для Яндекс Игр)

Рабочее название: Business Empire. Версия: 0.1 (MVP). Платформа: Яндекс Игры (HTML5, сенсор + мышь).

## 1. Концепция

Игрок — предприниматель: начинает с уличного ларька и через апгрейды, найм сотрудников и покупку новых бизнесов строит корпорацию. Механика простая: **нажимай — зарабатывай — покупай апгрейды — получай доход даже офлайн**.

Целевая аудитория: женщины 55+, Россия (ядро платформы), 1 устройство, сессии 5–15 минут, 2–4 захода в день.

## 2. Ядро геймплея (MVP)

1. **Клик**: тап по зданию → мгновенная прибыль (кликер из шаблона — основа).
2. **Бизнесы** (10 штук): Ларёк → Палатка → Магазин → Кафе → АЗС → Офис → Отель → Завод → Аэропорт → Корпорация. Каждый имеет цену, базовый доход и апгрейды.
3. **Апгрейды** (множители): ×2 прибыли бизнеса, ускорение клика, авто-доход «менеджер» (включает офлайн-доход).
4. **Офлайн-доход**: до 2 часов накопленного дохода при возврате (главный крючок удержания + повод для rewarded-рекламы ×3).
5. **Престиж (после MVP)**: сброс за «Престиж-очки», дающие глобальные множители — долгосрочный повод играть месяцами.
6. **Ежедневная награда**: календарь на 7 дней (возвращаемость).

## 3. Экономика (ориентиры)

- Стоимость следующего бизнеса ≈ ×10 от предыдущего, доход ≈ ×5 — классическая кривая idle-игр.
- Апгрейды удваивают цену каждый уровень, доход ×2.
- Валюты: монеты (мягкая) + алмазы (премиум, после MVP — покупки).
- Баланс MVP: первый бизнес покупается за ~30 секунд, 10-й — за ~2 недели казуальной игры.

## 4. Монетизация (по убыванию важности)

1. **Rewarded-реклама** — основной источник:
   - ×3 к офлайн-доходу (1 раз за заход),
   - ×2 к доходу на 30 минут,
   - бесплатный ускоритель клика ×2,
   - удвоение награды ежедневного календаря.
2. **Interstitial-реклама**: не чаще 1 раза в 3 минуты, между «событиями» (покупка бизнеса, возврат офлайн-дохода).
3. **IAP (после MVP)**: пакеты алмазов; «Без рекламы на 30 дней»; стартовый пакет за 99 ₽ (самый продаваемый формат на платформе).

## 5. Интеграция SDK Яндекс Игр

| Функция | Использование |
|---|---|
| `YaGames.init()` | инициализация |
| `player.get/setData` | сохранения (прогресс, настройки) |
| `adv.showRewardedVideo` | rewarded-реклама |
| `adv.showFullscreenAdv` | interstitial |
| `leaderboards` | «Богатейшие магнаты» (соц. механика) |
| `getPurchases/purchase` | IAP (после MVP) |
| `flags` | удалённая настройка баланса (правки без релиза) |
| `getPayments` / `onReadyToPurchase` | консультант оплаты |

Локально работает заглушка `sdk.js` — перед публикацией заменить на официальный SDK с https://yandex.ru/games/developers/docs/sdk/sdk-download.

## 6. Метрики успеха (целевые значения)

| Метрика | Цель | Зачем |
|---|---|---|
| D1 | ≥ 35% | отсечка для бесплатного трафика платформы |
| D7 | ≥ 10% | глубина удержания |
| Сессий/день | ≥ 2 | повторы захода = rewarded-показы |
| Rewarded показы/игрока/день | 3–5 | основной доход |
| % игроков, дошедших до 5-го бизнеса | ≥ 30% | проверка кривой мотивации |
| Средний плейтайм/день | ≥ 15 мин | доход с рекламы |

## 7. План релиза

1. **MVP (неделя 1–2)**: клик + 10 бизнесов + 30 апгрейдов + офлайн-доход + сохранения + rewarded/interstitial.
2. **Хардк (неделя 3–4)**: ежедневная награда, лидерборд, престиж, баланс по данным бета-теста.
3. **Запуск**: ZIP без вложенной папки → games.dev.yandex.ru → модерация (~1–5 дней).
4. **После запуска**: следить за D1/плейтаймом, крутить баланс через `flags`, добавить IAP и сезонные ивенты (НГ, 8 марта — сезонность аудитории).

## 8. Чего НЕ делаем в MVP

Никакого 3D, звука с закупкой, сетевого мультиплеера, сотен уровней контента. Всё, что затягивает релиз, — позже, по данным реальных метрик.
