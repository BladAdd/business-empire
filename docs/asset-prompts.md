# Промты для генерации ассетов «Бизнес-Империя» (Qwen 3.8 Max)

## Как пользоваться

1. Открой Qwen 3.8 Max (десктоп/веб).
2. Скопируй **СТИЛЬ-БЛОК** (ниже) + нужный промт целиком — одной строкой сообщения.
3. **Скачай картинку из чата**: наведи на сгенерированное изображение → кнопка «Скачать» (или ПКМ → «Сохранить изображение как…»). Пока ты её не скачал, она живёт только в облаке Qwen и в игру не попадёт.
4. Сохрани файл по указанному в промте пути в папке проекта `assets/` (имена файлов — в таблице внизу).
5. Игра **сама подхватит файл** по имени — ничего в коде менять не надо. Приоритет: PNG → SVG → эмодзи. Если PNG нет — покажется встроенный SVG-арт.

## 24. CSS-анимации кодом (делает Qwen-кодер, не генератор картинок)

> Файл `js/anims.css` не нужен — добавь анимации в существующий `<style>` блока `index.html`: пульсация главной кнопки клика (мягкое увеличение масштаба каждые 2 сек), золотое свечение вокруг кнопки при активном бусте (класс .boost-active на #tapBtn), появление toast-уведомлений, плавное появление карточки лидерборда (scale 0.9 → 1 + opacity). Все анимации должны быть лёгкими для слабых устройств (только transform и opacity), с prefers-reduced-motion поддержкой.

## 25. Звуки кодом через Web Audio API — `js/audio.js`

> Создай файл `js/audio.js` для игры «Бизнес-Империя» (idle-тайкун, аудитория 55+): синтез всех звуков через Web Audio API без внешних файлов. Звуки: click (короткий мягкий тык, 60 мс, треугольная волна 300→150 Гц), coin (звон монеты, два быстрых синусоидальных тона 1000 Гц + 1500 Гц с экспоненциальным затуханием 150 мс), buy (фанфары: 3 ноты C5-E5-G5, квадратная волна, мягкая), upgrade (восходящее арпеджио из 4 нот мажорного аккорда, 250 мс), reward (победный джингл из 6 нот, последняя — длинная с вибрато), boost (свип вверх 200→2000 Гц за 400 мс), error (низкий гудок 110 Гц, 300 мс), плюс тихая фоновая мелодия-луп (минорный пентатонический мотив, 8 нот, цикл 8 сек, громкость 15%). Экспортируй объект `window.AudioManager` с методами play(name), setMuted(bool), setVolume(v). Сделай автозапуск звука после первого жеста игрока (политика автоплея). Подключи кнопку 🔊 в нижней панели (переключатель mute).

## 26. Интеграция ассетов в игру (делает Qwen-кодер)

> В `js/game.js` проекта «Бизнес-Империя» замени все эмодзи бизнесов на загрузку картинок по конвенции: `assets/img/business-<id>.png` (id из списка BUSINESSES: stall, tent, shop, cafe, gas, office, hotel, factory, airport, corp). Реализуй кэширование успешных/проваленных загрузок, при отсутствии файла — показывай эмодзи как сейчас. Аналогично: кнопка клика (иконка текущего топ-бизнеса), фон страницы (assets/bg.png), float-num монеты (assets/img/coin.png маленькая вставка). Не ломай существующую вёрстку и логику.
