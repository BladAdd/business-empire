# «Бизнес-Империя» — idle-кликер-тайкун для Яндекс Игр

Казуальная игра для платформы [Яндекс Игры](https://yandex.ru/games): от ларька до корпорации — кликай, покупай бизнесы, апгрейды, офлайн-доход. Нацелена на ядро аудитории платформы (женщины 55+, Россия) — самая прибыльная ниша при минимальных затратах на разработку.

## Документы

- [`docs/market-analysis.md`](docs/market-analysis.md) — анализ рынка Яндекс Игр (официальные данные + разбор топа каталога, обоснование выбора жанра)
- [`docs/gdd.md`](docs/gdd.md) — геймдизайн: механики, экономика, монетизация, интеграция SDK, KPI, план релиза

## Статус

MVP-концепт готов (v0.2): 10 бизнесов с апгрейдами, сила клика, офлайн-доход (×3 за рекламу), ежедневная награда, буст ×2 на 30 мин, лидерборд, звуки (Web Audio), спрайт-анимации (клик/монета/конфетти), фоновый арт и иконки с авто-подхватом из `assets/`.

**Ассеты:** кидай PNG в `assets/img/` (иконки бизнесов: `business-stall.png` … `business-corp.png`, монета `coin.png` и т.д.), спрайты — в `assets/sprites/` (`click-burst.png`, `coin-fly.png`, `confetti.png`), фон — `assets/bg.png`, иконка — `assets/icon.png`. Игра сама подхватит файл по имени; нет файла → эмодзи. Промты для генерации: `docs/asset-prompts.md`.

## Локальный запуск

```
npx serve
```

Открой `http://localhost:3000`. Реклама и лидерборд в локальном режиме неактивны (заглушка `sdk.js`).

## Публикация на Яндекс Играх

1. Замени `sdk.js` на официальный: https://yandex.ru/games/developers/docs/sdk/sdk-download
2. Запакуй в ZIP (файлы в корне архива: `index.html`, `sdk.js`, `js/`)
3. Загрузи в [Кабинет разработчика](https://games.dev.yandex.ru/) → «Добавить игру», укажи `index.html`
4. Создай лидерборд с именем `total_money` (вкладка «Лидерборды»)

## Ключевая монетизация

Rewarded-реклама (×3 офлайн-доход, ×2 доход, ускорители) + interstitial (не чаще 1/3 мин) + IAP после MVP. Подробности и целевые метрики — в `docs/gdd.md`.
